# Web 读卡 / dump 工具

读取 TYYZ 水卡信息：**消费钱包 / 水控2 / 水控1**（水控1 需手动填密钥）；
也可以载入 dump、可视化修改字段（金额 / 时间 / 卡面 / 清空扇区）并下载新 dump。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 单文件网页（界面 + PN532 协议 + 解析），直接使用 |
| `bridge.py` | **预留**：本地桥，给"破解 S8/S9"功能用，当前页面未启用，可忽略 |
| `bridge.log` | 桥的日志（仅在使用桥时产生） |

## 启动

```powershell
# 关掉 PCR532 / PN532CardReader（释放 COM3）
cd web
python -m http.server 8080
```

Chrome 打开 `http://localhost:8080`。

## 使用

1. **连接读卡器** → 选 `USB-SERIAL CH340 (COM3)`；
   - 自动尝试 波特率 × DTR/RTS × 唤醒方式，日志会显示命中的组合（正常是 `115200 / DTR=true / RTS=true / wake=false`）；
2. **读取卡片** → 读 Sector 0–4：卡号/姓名/开卡日期、消费钱包余额、水控2 余额、最近两笔交易；
3. 想读**水控1**：在"水控1 密钥"里填 S8 或 S9 的 KeyA（12 位 hex），填一个即可，另一个自动推；
4. **读卡 / 解析** 页下方：也可以直接上传 `.dump` 或粘贴 1024 字节 hex，解析结果和读卡结果显示在同一区域；
5. **编辑 dump** 标签页：
   - 载入 `.dump` / 粘贴 hex / 直接「载入刚才读到的卡」；
   - 表单自动填入当前值，改哪个生效哪个（校验、GBK 姓名编码都在浏览器里算）；
   - 支持：水控1/水控2 余额、水控2 b4/b10、清空指定扇区（保留密钥区）、
     模拟消费/充值（自动切记录、序号+1、当日累计）、卡面信息；
   - 点「生成新 dump」→ 下方实时预览 → 可改「输出文件名」→「下载 .dump」。

   对应的命令行版本见 `scripts/dump-edit.py`，两者算法一致（已做逐字节比对）。

6. **写入卡片**（编辑页底部，需先连接读卡器）：
   - 勾选「我确认这是测试卡」→ 选扇区 → 「写入卡片」；
   - 默认只写数据块（0–2），尾块需额外勾选（可能锁卡）；
   - **M1 是整块 16 字节覆盖**，没有部分写：选中的块会被 dump 内容**无条件直接替换**，
     不管卡上原来是什么；
   - 写入后自动回读校验，进度条 + 逐块日志；
   - S8/S9 密钥沿用「读卡 / 解析」页输入框，留空则跳过。

## 常见问题

| 现象 | 处理 |
|---|---|
| 串口能开但 0 字节 | 先运行 `C:\工具Tools\PCR532\nfc-bin\nfc-list.exe`（libnfc 初始化复位 PN532），再点连接 |
| `port is already open` | 点「重置串口」，或刷新页面；确认没有其他程序/标签页占用 |
| 连接失败 | 拔插读卡器 USB（换口），确认设备管理器里 CH340 出现在 COM3 |

## 密钥关系

```
KeyA(S1–3) = UID 推导（已破解）
KeyA(S4)   = 04 || ~UID || 81
KeyB(S4)   = A2 02 0B C0 71 8D
S9 KeyA    = S8 KeyA ^ 00 01 20 00 00 04
S8/S9 KeyB = KeyA ^ 60 84 2D 00 00 0C
```
